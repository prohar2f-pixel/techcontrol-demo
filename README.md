# TECHCONTROL demo — GitHub Pages

Статическая демо-концепция сайта управления строительной техникой. Показатели, доступность парка и контакты в демонстрации являются заглушками и требуют подтверждения.

Публикация запускается workflow GitHub Pages при отправке изменений в `main`.

Ожидаемый адрес: https://prohar2f-pixel.github.io/techcontrol-demo/
